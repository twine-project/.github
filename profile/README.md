<h1 align="center">TWINE</h1>

<p align="center">
  <strong>Twin-based Web Interoperable Network for Engagement</strong><br>
  Open, federated and human-centric Web 4.0 and Virtual Worlds for European cities

Across Europe, digital twins and immersive services remain fragmented and difficult to scale. **TWINE** demonstrates how open, federated and human-centric infrastructures can make such services interoperable, accessible and trusted for citizens, cities and SMEs.

### What we are building

1. A **federation-ready Web 4.0 architecture** with open-source building blocks.
2. **Connectors, profiles** and Europe's first **Minimum Interoperability Mechanism (MIM)** for immersive civic services.
3. **Cross-city federation**, demonstrated through pilots in Rotterdam, Tampere and Flanders, with seamless identity continuity, portability and guidance.
4. **Sustainability** through open licensing, replication toolkits, governance playbooks and community building.

The code developed in the project will be published in this organisation as the building blocks are released.
